# Navoraa Website

Corporate website for Navoraa — enterprise cloud, AI, security and platform architecture consulting from Perth, Western Australia.

## GitHub Pages

This repository includes an automated GitHub Pages workflow. Pushes to `main` build and deploy the static website.

The initial Pages URL is:

https://navoraa.github.io/navoraa-website/

The production custom domain can be configured later in **Settings → Pages**.
